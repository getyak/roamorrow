在本目录用 `python3 -m http.server 8343 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8343/prototype.html`。端口占用时选择空闲端口。若已有上级目录预览服务，复用服务并追加本目录路径。

示例主流程：点“找一家安静的咖啡馆” → 选一个候选 → 放进今天 → 看预览并改时间 → 确认 → 查看下一步。还可以点图钉、问这家、收起面板、查看今天、打开资料侧栏，以及体验语音转写示意。

已有确认体验时，预览会明确说明替换或调整；撤销只作用于一个有效修改记录。提问范围与当前查看项独立。所有数据都在当前页面内存中，刷新重置。本轮演示仅管理一个可编辑的新增体验槽位；完整多段 Trip 和原生系统能力未在此实现。

`index.html` 是 1800×1240 的静态设计板入口，可以用 `npx --yes hyperframes@0.8.216 snapshot --at 0.5` 重新导出。它关闭了交互过渡；`prototype.html` 保留轻量的面板过渡和 Reduce Motion 降级。检查中的 CSS 时钟警告来自共用的交互样式，滚动容器溢出警告对应可滚动任务正文。完整内容和主要按钮另作了人工视觉检查。

本轮没有更改 SwiftUI 代码、占用共享模拟器、调用真实麦克风/定位/模型、预订或付款；浏览器交互验证不能代替原生验收。
