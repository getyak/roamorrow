# 46 秒 UI 概念演示

已选方向（设计师建议）：同一旅程的一天。下一步先到手边 → 拉开旅程目录 → 核对延误来源 → 看清金额退款 → 确认一项偏好 → 收起手机，锁屏接力。
其他方向：资料到行动（从导入确认信一路到 next action）；出门前后（用离线与权限降级表现可靠性）。本轮采用前者，直接回应侧栏和原生在场体验。
