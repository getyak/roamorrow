主路径是「对话回答 → 同一地图页高亮候选 → 选点 → 聊聊这里 → 带地点范围回到来源对话」。地图也能从底部导航独立进入；浏览、筛选、平移和收藏不改历史回答或已确认行程。「放进今天」仍需经过预览与确认。

设计板展示 `chat → map → scoped`。短片依次展示 `chat`（0–3.5 秒）、`map`（3.5–7 秒）、`typing-scoped`（7–10.5 秒）、`saved-map`（10.5–14 秒），1920 × 1080、30 fps、无音轨。键盘只表示占用区域，不是原生输入法接入。没有拍摄系统操作，也没有绘制已核实路线。

所有入口复用本地 `assets/data.js → assets/map-flow.js → assets/app.js`。`film/assets` 链接到同一份 V4 素材与样式；品牌素材、地图瓦片和 GSAP 继续链接 V3，渲染不需要在线瓦片。预览和资源验收由主任务统一安排，复用已有服务。

本目录是轻量 HTML 交互设计稿。地点、候选、来源和行程为演示数据；不读取位置、麦克风、私人文件或账号，不连接模型、支付或预订服务。原型与工具评测是不同证据：这里展示的 UI 不证明原生导航、真实工具链、营业状态或真实旅行建议已经通过验收。

已导出设计板与短片，并完成浏览器主路径和独立状态/焦点审查。HyperFrames 布局、运行时与对比度检查无错误；嵌套时间轴和小字号的提示已保留。视频和原生工具测试的最终证据见验证记录，不把浏览器原型等同 SwiftUI 四项导航、系统输入法或真实模型全链路。
