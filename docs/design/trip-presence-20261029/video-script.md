# 《下一步，已经在这里》UI 设计短片

按用户指定的 youtube-script / youtube-script-writer 阅读并使用继任技能组织脚本；本次是 46 秒 UI 概念演示，不套用长视频篇幅。观众是产品决策者与 iOS 设计/研发同伴；目标是看懂新的主信息层级与执行边界。采用音乐与界面原生文案，不加旁白或字幕轨。

## 标题与封面备选

1. 好奇：旅行助手，打开后第一眼该看见什么？封面为首页行动卡，强调「现在出发」。
2. 结果：Roamorrow iOS：下一步，已经在这里。封面为地图和清晰的 16:10 截止时间。本轮采用。
3. 观点：把一次确认，留给每一笔花钱。封面为价格与退款政策；不重复标题全文。

## 三个开场

- 观点：直接出现「该去上野站了」的首页，把行动放在提问前。
- 故事：一封延误通知对照旧时刻，展示为什么需要一份可信 Trip。
- 反差：先展示收起手机后的锁屏下一步，再回到 App 解释同一行程如何延伸出来。

采用第一个开场，最快交代设计改善点。其余两种作为未来独立短片方向；本轮不混成三段预告。
