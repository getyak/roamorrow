# 一页交互稿：把浅草寺拖到另一天

GET-294 / 2026-10-29。可点击版：启动原型后打开 `/interaction`。这里的换天改变 stop 的归属，不改变 POI 坐标。日色为固定 day ID 的属性，不以颜色单独传达信息。

手机 390 × 844：地图占上半屏，底部行程面板与固定三天切换带；面板内部滚动，页面不横向滚动。长按 350ms 进入换天模式（移动 8px 前不得劫持地图平移）；日期带升到手指上方，靠边自动滚动。松手落到某一天仅决定归属，默认在涉及两天内顺路重排（保留固定预约与首站）；指定顺序在时间轴内拖到某两项之间，并使用 preserve。地图空白处松手取消。原型实现 Pointer Events 跨天拖动及点击/键盘菜单，真实触屏长按、边缘滚动与震动仍需原生/真机验收。

| 阶段            | 画面与动作                                                        | 状态与约束                                                |
| --------------- | ----------------------------------------------------------------- | --------------------------------------------------------- |
| 平时            | day 标签 + 名称 + 1/2/3，与日色并用                               | 所有天可看，当前天路线较强，其余降低不透明度              |
| 按下 / 拿起     | pin 或列表 drag handle 放大，源位置保留占位                       | 不让用户误以为 POI 被移动到任意坐标                       |
| 拖动            | 三天停靠区显示，目标区域高亮；单独数字计数更新                    | 本地 preview，不改已保存版本；Esc / 落空取消              |
| 放下            | 显示「正在更新第 1、2 天」与旧路线虚线                            | 禁用第二次提交，同一请求重试复用 key；不每像素调用工具    |
| 成功            | 源天/目标天同一帧替换，重排涉及两天的未锁定顺序，保留明确插入意图 | map version +1；pin 与时间轴同一 snapshot；短 diff + 撤销 |
| 多了交通 / 空天 | 显示两天交通变化；源天为空时给「加一个地点」                      | 不自动补点、不擅自删掉空天、不静默重新聚类三天            |
| 算不了 / 超时   | pin 回原位，保留旧行程；明确「重试」                              | 不提交任何一天；provider 异常不变成 0 分钟                |
| 过期版本        | 「地图已在别处更新」+ 读取最新版本                                | 不自动 overwrite；让用户重放拖动意图                      |
| 固定预约        | 拖动时说明「预约绑定原日期，不能直接换天」                        | 不静默改预约日期；v1 不支持改约                           |
| 未知交通        | 明确「已移到草案，交通时间待核查」                                | 到达时间是 null；固定预约时刻可展示但到达可行性仍未知     |
| 撤销            | 成功后操作条保留；失败不清掉最后可撤销 edit                       | 仅撤销最后一次 edit，新版本补偿写；其他编辑后禁用并说明   |
| 访客            | 可看图；编辑控件换成「复制并编辑」                                | view token 不能授权写原图；副本是新 map ID                |

键盘与无障碍：pin/条目都有 `button`、名称、所属天与顺序；焦点菜单有「移到第 2 天」「上移」「下移」；拖动不是唯一路径。更新结果用 `aria-live=polite`，失败 `role=alert`。焦点在编辑后留在原 stop，不跳到页首。日色与白底对比、目标最小 44px，尊重 prefers-reduced-motion。原型浏览器键盘路径不等于 VoiceOver / TalkBack 实机通过。

时间轴联动后续页：拖开始时间是 `set_start_time`，地点高亮受影响后续段；拖停留结束是 `set_stop_duration`。预约固定时段不会被挤走。地图 hover 只改变选中态、不刷新模型。选区规划优先次序为「选区域 → 看真实候选 → 明确加入」；不要让画圈本身触发生成并覆盖现有行程。
