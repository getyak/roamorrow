# 聊天手感与「我」页设计

GET-338 · 2026-10-30

用户明确要求直接设计并实现。本方案沿用 SwiftUI、iOS 17+、现有暖纸色/墨绿及已有功能入口。

## 目标

- 数千条消息时，滚动帧不再整理全部历史或扫描全部消息。
- 输入只保存轻量草稿；点击发送先显示原话，序列化与文件写入让出主线程。
- 正在阅读历史或拖动时，新回复不抢位置；主动发送和「回到最新」明确回到底部。
- 保留旧历史兼容、工具开始前落盘、结果复用、失败重试及遗忘边界。
- 「我」页有清楚的视觉层级，所有原有资料、档案、同行、订阅、设置与审核入口仍可达。

## 方案选择

保留 SwiftUI 的惰性列表，增加缓存的时间线投影与独立滚动策略。重写 UIKit 聊天容器会扩大状态迁移范围；仅缩短动画无法解决整段排序和同步大文件写入。此次采用前者，保留 iOS 17 回退，并在 iOS 18+ 使用原生滚动阶段通知。

### 数据与滚动

1. 消息/邀请变更时重建展示投影，预先计算 ID、时间分隔、引用关系及新增事件；滚动与进度变化读取缓存。
2. 每个 ForEach 元素只有一个稳定容器，正文分段每次 body 只算一次，格式化文本使用值语义子视图。
3. 滚动策略区分跟随、读历史、手指/惯性滚动和显式跳转；位置记录不变时不重复发布状态。
4. 新内容滚动请求合并到下一次布局；长距离回底部直接定位，避免穿过数千条消息做动画。
5. 发送保留键盘，输入框高度收缩时保持底部意图，避免键盘收起与消息插入互相争抢。
6. 地图返回固定以来源消息 ID 定位，即使 ID 未变也显式重放定位。键盘展开/收起后保留历史目标；布局引发的可见行回写不替代用户阅读意图，真实拖动/惯性仍可更新锚点。
7. 阅读检查点只供持久化使用，不发布高频显示观察通知；恢复 token 与时间线内容仍明确驱动界面。iOS 18+ 将默认底部锚点限制在初始位置与短内容对齐，避开超长行估算高度变化时的重复锚定。
8. 新手势让所有旧的自动定位请求失效，显式发送/回最新除外。普通尺寸变化只用于观察；键盘完成只重放有效的历史锚点，不从过期检查点重建当前跟随/未读意图。长消息中尚无可用历史锚点时保留原生偏移。

### 持久化与故障

- 草稿使用对应会话的轻量 sidecar，带版本、会话标识和递增 revision。旧 v1 JSON 可读；较旧草稿不能在发送后复活，发送期间新输入仍能恢复。
- 完整快照的异步编码/原子写入经过带 ticket 的写入器；较旧的异步写入不能覆盖较新的同步工具收据。清空先使旧 ticket 失效。
- 发送前先原子保存小型 outbox 接收记录，再消耗草稿与呈现原话。重启会去重恢复为可重试消息，不自动执行；已落盘媒体使用引用，避免发送时再编码二进制。未知版本原样保留，显式清空覆盖精确命名空间。
- 完整历史缓存不可变消息的 JSON 编码；工具计划、开始与结果依旧原子落盘，复用未变化的历史字节。清空使缓存代次失效，旧后台编码不得把遗忘内容放回缓存。
- 发送等待 durable acceptance 后才调用模型；最终问答保存成功后才进入记忆。工具日志和 follow-up 的同步原子事务保持原有约束。
- 等待保存时取消、清空或输入下一句话，不得启动旧模型请求、复活旧记录或覆盖新草稿。磁盘失败继续保留可重试内容。

### 「我」页

- 原生大标题与右上设置；左对齐头像、姓名、编辑入口，替代居中的大渐变卡片。
- 收藏/探索只显示真实计数，静态、清楚，不使用进度环或逐个跳动的数字。
- 旅行档案是主内容入口；好友、消息、旅伴组成「同行」分组；订阅与偏好处于次级层级。
- 暖纸底色、墨绿正文、细分隔线、少量实色表面。避免卡片套卡片和装饰玻璃。
- Dynamic Type、大字号纵向布局、深色与 Reduce Motion 均需验证；所有主要触点至少 44pt。
- 空收藏引导返回附近；嵌入页通过显式回调切换地图，不能调用无效 dismiss。

## 验收

- 真实 Store 宿主：5,000 条消息输入时不重写历史；重开草稿、发送不重复、失败、取消/清空、新草稿与异步旧写入边界。
- 纯策略：拖动/惯性中收到回复、读历史、显式发送、回底部、删除/恢复锚点和大批量变化。
- 原生：长消息/引用/媒体、快速滑动、边滑边收/发消息、键盘、切换页面、恢复、大字号、浅/深色及空/有数据「我」页。
- 保存宿主优化构建和原生模拟器的独立证据；不把宿主时间或模拟器手感称为真机帧率。
- 独立审查确认持久化/恢复安全，最新提交适用 CI 通过后交付。

原生 API 依据：[滚动阶段](<https://developer.apple.com/documentation/swiftui/view/onscrollphasechange(_:)>)、[滚动几何](<https://developer.apple.com/documentation/swiftui/view/onscrollgeometrychange(for:of:action:)>)。
