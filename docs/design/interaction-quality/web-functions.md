# 当前 Web 页面、入口与功能目录

本目录按用户能看到的页面和操作归并，依据冻结后的工作树源码、[当前机器清单](current/inventory.json)、动态文案、静态数据和页面组合人工核对。**它不是按钮计数，也不是浏览器验收报告。**

当前快照扫描 220 个文件，提取 974 个跨端源码候选（Web 110、iOS 864），使用 44 个功能组归并，未归组 0、解析诊断 0。候选包括复用组件、调用点、手势、事件和呈现关系，不能称作“974 个按钮”。上级目录的固定基线仍保留 892 个候选，未被当前清单覆盖。

最新补充：体验/行程示例页在320/390px中英文无横向溢出；示意地图的可见标记为完整44×44px语义按钮，缩放后命中范围仍受边界约束；指南来源与行程分享明确标为示例，分享动作送达仍未确认。详见[evidence/round02-web-browser-checks.json](evidence/round02-web-browser-checks.json)。

下文“具备 / 支持 / 调用”仅表示读到了对应实现。本文没有运行浏览器；实际点击、焦点落点、触摸命中率、网络保存和外部服务可用性由主任务的浏览器证据另行验证。没有据此宣称任何项达到 96 分。

## 验证边界

1. 这些名称、目的地和状态来自源码核对，未把源码存在等同点击通过；所有运行验证仍由主任务另记。
2. 分发目标随部署配置变化；地图、定位、语音、分享、系统邮件、API保存和权限需在对应环境实测。
3. 动态项、renderer、调用点、重复入口和SDK控件不能直接相加为按钮总数；静态数据规模也不是产品容量。
4. 本文和 `current/` 是当前实现目录，上级固定清单与原始设计分析是基线证据。后续源码再变时须重扫，不能把基线问题直接认作当前失败或已经修复。
